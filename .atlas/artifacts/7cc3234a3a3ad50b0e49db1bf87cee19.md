# Agents pane runtime model picker

`/model` and `/agent` with no argument now open the shared picker modal in the agents pane.

Resolution order:
1. Active ACP session advertises a select config option id `model` or category `model`.
2. Otherwise the resolved agent binary is probed with `--ee-config-choices model` using its resolved launch env, covering OpenCode and OpenRouter.
3. If neither yields choices, the command reports the failure and keeps `/model <model-id>` as the manual path.

Behavior:
- Picker kind `AgentModels`, title `Switch Model`, badge `MODEL`.
- Current model is preselected. For remote choices, the main `MODEL` / `*_MODEL` env slot wins over critic/classifier/small model slots.
- Model IDs travel in `PickerItem.detail`; labels remain human-readable.
- Selecting a model calls the existing `agents_model_command`: config option route when advertised, otherwise `session/set_model`.
- Turn-active block reuses the existing model-switch guard.
