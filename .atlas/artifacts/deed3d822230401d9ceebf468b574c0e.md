# Implementation: ACP `/usage` command for ee-agent-opencode

## What changed

- New `crates/ee-agent-opencode/src/usage_command.rs`:
  - `USAGE_COMMAND_NAME = "usage"` and `usage_available_command()`.
  - `UsageReporter` trait + `ConfigUsageReporter::resolve(dotenv)`; resolves the
    same env/.env/config inputs as `--usage` and stores only the resolved
    `UsageProbe` (API key + org id).
  - `UsageCommandProvider<P>` wraps any `AgentProvider`:
    - appends `/usage` to `new_session`, `load_session`, and `resume_session`
      command lists unless already present;
    - intercepts exact `/usage` prompts before the inner provider/model;
    - streams a bounded, control-character-safe text report through
      `UpdateSink::agent_message_chunk`;
    - honors the session cancellation watch (`StopReason::Cancelled`);
    - delegates every other trait method, including auth and config options.
  - Formatting shows workspace id, Go rolling/weekly/monthly percent +
    rate-limited + reset time, budget per/scope + spent/limit + reset, flags,
    notices; hard cap 8 KiB.
- Orchestrator extension:
  - `OrchestratorProviderConfig::additional_commands`.
  - `initial_commands_with(recovery_enabled, additional)` dedupes by name.
  - `agent_impl` includes additional commands in session init (new/load/resume)
    and in prompt-time command re-advertisement.
- Wiring:
  - `opencode_orchestrator_config` advertises the usage command.
  - `opencode_multi_model_provider` wraps the orchestrator with
    `ConfigUsageReporter`; it now takes the parsed dotenv map.
  - `opencode_multi_model_provider_with_codecs` wraps with a deterministic
    disabled reporter (advertised + intercepted, no network).
  - `main::run` reads `.env` once and passes it to config + reporter.
  - `ee-agent-openrouter` untouched; its config has no additional commands.

## Caveat

The live client transcript shows the user `/usage` echo and the agent reply, but
the exchange is not added to the inner orchestrator's model conversation or its
load-replay transcript. It does not pollute future model context.
