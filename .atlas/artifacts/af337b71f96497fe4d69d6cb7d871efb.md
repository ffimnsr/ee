Fix: mouse click on a collapsed tool-call row expanded every tool detail in the response group.

Root cause: TranscriptRowAction::ToggleToolDetail only carried the ResponseGroupId, and the click handler called agents_toggle_selected_tool_details(), which toggles the group-wide expanded_tool_details set. Rendering also decided detail visibility only per response group.

Change:
- Added AgentThreadUi::tool_detail_overrides (response group -> tool-call id -> expanded bool) and tool_call_detail_visible / toggle_tool_call_detail helpers.
- Rendering resolves detail per ToolCall item, with the per-tool override winning over the group-wide flag.
- TranscriptRowAction::ToggleToolDetail now carries { group, tool_call_id }; mouse click toggles only that tool.
- Ctrl-E remains group-wide and clears per-tool overrides so it stays authoritative.
- Initialization, transcript reset, and tests updated.
