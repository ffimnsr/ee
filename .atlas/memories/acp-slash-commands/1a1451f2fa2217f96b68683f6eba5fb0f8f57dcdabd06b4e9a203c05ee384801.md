ACP supports advertising /usage: `available_commands_update` carries `AvailableCommand { name, description, input }`, and commands run as ordinary `session/prompt` text. ACP's `usage_update` only models context window (used/size) and cumulative cost; it has no rate-limit/quota windows, so OpenCode Go rolling/weekly/monthly meters and workspace budgets must be rendered as text (or `_meta`). `crates/ee-agent-opencode/src/usage.rs` already fetches them, but only `--usage` calls it. `initial_commands` in orchestrator does not advertise `usage`. ee-cli already lists `usage` in `PROVIDER_OWNED_SLASH_COMMANDS` and forwards it when advertised. Recommended: provider decorator in ee-agent-opencode that appends the command in new/load/resume session and intercepts `/usage` before the model, not a global orchestrator command. Keep advertisement static; treat 403 as "not available for this workspace". Full evidence: source_id f0dc28403898bcd162398a3f16cfb28a.
