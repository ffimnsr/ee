Grammar offload verdict: good for installed size (55 .so ~49MB -> 3 core ~1.4MB; gzip 5.4MB -> 176KB, release archive only -5.2MB). Not safe as default with only rust/toml/yaml because activation requires local toolchain: cc + rustc (effective_host_triple), cargo for 20 crate-sourced grammars, git for 38 git-sourced. Missing grammar disables syntax spans, semantic motions, reindent, folds/tags silently; no in-editor prompt. Runtime loading is already lazy. Safe path: add --languages to build-runtime.sh/install-tree-sitter-runtime.sh; keep full official release; for minimal default add signed prebuilt language packs + ee do runtime install <lang>, or curate core set (~37 libs under 500KB + rust = 6.6MB).
