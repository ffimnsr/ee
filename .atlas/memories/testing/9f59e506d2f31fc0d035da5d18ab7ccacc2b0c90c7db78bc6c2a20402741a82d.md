ee-chat-completions now routes every model exchange through the `transport::HttpBackend` seam (LiveBackend, RecordingBackend, Replay) and a normalized chunk-source `HttpResponse`. Record a real provider once with `EndpointTransport::recording` (or the env-driven `cargo run -p ee-chat-completions --example record_exchange`), persist a bounded JSON `Cassette`, then replay deterministically in tests with `EndpointTransport::with_backend(..., Arc::new(Replay::with_chunk_size(cassette, n)))`. Matching is method + exact body with path as tie-breaker; recorded sequences (429 then 200) replay in order; unknown requests fail closed. Credentials are redacted from headers and URL queries; request bodies still contain prompts, so review cassettes before committing. Fixtures: crates/ee-chat-completions/tests/fixtures/.
