MCP server-level trust is safe only as a pinned capability grant, not blanket allow. Bind grant to workspace trust + canonical transport fingerprint + pinned tool manifest/schema digest. Read tools/resources can be broad; write tools must be explicitly pinned and workspace-bounded; execute stays under command trust. External [mcp.servers] calls are agent-native and currently outside the editor trust store; ee-proxy scope is the feasible v1. Existing bulk read trust is `ee_mcp_safe_read` (35 tools, finite 30d/10k grant). Full assessment: source_id 0864e507b08aad2793e3c2dcb340d2bd.
