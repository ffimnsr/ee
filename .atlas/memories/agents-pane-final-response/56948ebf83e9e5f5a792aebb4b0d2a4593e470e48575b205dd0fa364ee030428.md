The orchestrator emits an evidence-derived FinalResponse every turn as an extra agent_message_chunk under the reserved id prefix `ee-final-response-` (now `FINAL_RESPONSE_MESSAGE_ID_PREFIX` in ee-agent-protocol). It is host diagnostics, not model prose. The ee-cli agents pane now intercepts those chunks in `apply_session_update` and writes them to the private per-session evidence audit log instead of the transcript, matching the existing policy for `TurnEvidenceUpdated`. Regression test: `tests::agent_pane::transcript_tests::final_response_summary_goes_to_the_evidence_log_not_the_transcript`. External ACP clients still receive the chunk unchanged.
